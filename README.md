# PiChain Monitor

PiChain Monitor là ứng dụng theo dõi blockchain Pi Network thời gian thực, tối ưu hóa cho Pi Browser và nền tảng Pi SoloHost.

## Tính năng chính
- Theo dõi trạng thái Mainnet & Testnet.
- Cập nhật Block mới và danh sách giao dịch liên tục.
- Tra cứu số dư và thông tin ví Pi.
- Lưu trữ và ghim theo dõi danh sách ví yêu thích.
